# Tasks — Operational Framework Example

These are the implementation tasks Kiro generates from the design. For operational frameworks, "implementation" means writing documents and building tools — not deploying code.

## Task 1: Write Alignment Document — Executive Summary & Artifact Map
- [ ] Write the executive summary (team context, the problem, what changes)
- [ ] Create the artifact integration map (Mermaid diagram showing how existing artifacts connect)
- [ ] Define authoritative source rules (which artifact answers which type of question)

## Task 2: Write Alignment Document — Decision Pipeline
- [ ] Document the end-to-end pipeline with stage-by-stage breakdown
- [ ] Define gate criteria for each stage (what must be true before advancing)
- [ ] Create the master Mermaid flow diagram

## Task 3: Write Alignment Document — Scoring Model Upgrades
- [ ] Define customer/stakeholder priority multipliers with rationale
- [ ] Redefine the strategic alignment dimension against current goals
- [ ] Formalize tie-breaking rules
- [ ] Write scoring guidance with concrete examples per dimension per score level

## Task 4: Write Alignment Document — Escalation Protocol
- [ ] Define what qualifies as an escalation (criteria, source requirements)
- [ ] Document the 24-hour emergency triage process
- [ ] Create the trade-off document template
- [ ] Define the capacity cap and approval escalation path
- [ ] Write a concrete example scenario

## Task 5: Write Alignment Document — Cadences & RACI
- [ ] Define ceremony schedule (weekly, monthly, quarterly)
- [ ] Create the RACI matrix for all activities
- [ ] Document the fast-track rule for time-sensitive requests

## Task 6: Write Alignment Document — Capacity & Health
- [ ] Document the capacity impact assessment process
- [ ] Define the running capacity ledger format
- [ ] Define overallocation flag rules and resolution paths
- [ ] Define the five process health metrics with thresholds
- [ ] Document the retrospective trigger rule

## Task 7: Build Interactive HTML Tool
- [ ] Create page layout with sticky navigation
- [ ] Embed Mermaid diagrams with click-to-scroll interactivity
- [ ] Build collapsible detail panels for each framework component
- [ ] Add scoring reference table with calculator layout
- [ ] Add cadence calendar view
- [ ] Add process health dashboard reference
- [ ] Add print CSS for PDF export
- [ ] Test in Chrome, Firefox, Safari

## Task 8: Create All Templates
- [ ] Intake request template
- [ ] Scoring scorecard template
- [ ] Trade-off document template
- [ ] Decision record template
- [ ] Capacity ledger template
- [ ] Stakeholder request log template

## Task 9: Validation
- [ ] Requirements traceability check (every requirement maps to a document section)
- [ ] Dry run: process one real request through the complete pipeline using templates
- [ ] Edge case walkthrough: test each error handling scenario
- [ ] Cross-browser check for HTML tool
- [ ] Print-to-PDF check
